# AmiHASS logo

The transparent master is `AmiHASS-logo-master.png`. The website uses the same image in `public-web/assets/amihass-logo.png`. Preferences embeds a 48×48 four-pen adaptation in `include/amihass_logo.h`, mapped to the public screen palette. No image decoder, external file or custom screen palette is required.

`AmiHASS-logo-native.png` previews the embedded image with standard Workbench colours. Screen customisation may change its displayed colours.
