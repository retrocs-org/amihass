# Website changelog

Website changes are tracked separately from the application changelog.

## AmiHASS 0.3

### Features

- Bridge features section between Overview and Screenshots.
- PHP downloads with GitHub release versions, links and download counts.
- Separate application and SDK downloads with checksum links.
- AmigaOS screenshots of Preferences, Device Browser and Dashboard.
- Home Assistant introduction and official website link.
- NovaDock integration section and website link.

### Enhancements

- Dark design with shorter section text.
- Application downloads appear above the SDK.
- AmiHASS logo throughout the website.
- Installation guidance for curl, AmiSSL and certificates.
- Release metadata caching reduces GitHub requests.

### Bug fixes

- Missing releases show that AmiHASS has not been released yet.
- GitHub outages show an availability warning instead of invented downloads.
- Cached release information is marked when it may be outdated.
